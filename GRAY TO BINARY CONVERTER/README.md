# 4-Bit Gray to Binary Converter in Verilog

## Description

This project implements a **4-bit Gray-to-Binary Code Converter** using Verilog HDL.

The circuit converts a 4-bit Gray code input into its equivalent 4-bit binary output.

This is a **combinational circuit**, so it does not require a clock or reset.

## Features

- 4-bit Gray-to-Binary converter
- Combinational logic
- No clock required
- No reset required
- Tests all 16 possible Gray code inputs
- Compatible with Visual Studio Code
- Simulated using Icarus Verilog

Applications

Gray-to-Binary converters are used in:

Rotary encoders
Position sensors
Digital communication
Error reduction
Data conversion
FPGA and digital logic design
